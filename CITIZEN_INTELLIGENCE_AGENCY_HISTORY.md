## 🎯 Executive Overview

Citizen Intelligence Agency (CIA) began in **2008** with a simple but ambitious idea: use software engineering and open-source intelligence to make political activity more transparent and democratic institutions more accountable.

What started as a Java-based political transparency project evolved into a substantial platform for collecting, structuring, and analysing Swedish parliamentary information.

Its development history spans several generations of technology:

- 🏛️ **2008:** The first published version of Citizen Intelligence Agency.
- ☕ **2011:** A surviving Maven-generated engineering archive documents the project's early architecture, including ThinWire and XRadar reports.
- 📊 **Subsequent development:** A structured political intelligence platform with historical parliamentary data, analytical frameworks, and extensive database views.
- 🤖 **2026:** AI-assisted civic technology extensions, including Riksdagsmonitor, EU Parliament Monitor, and MCP integrations.
- 📦 **November 2026:** Hack23 public repositories archived, preserving the software and its engineering history.

The central idea has remained consistent throughout the project's evolution:

> **Make political information accessible, structured, measurable, and open to independent scrutiny.**

## 🏛️ 2. 2008: The Beginning of Political Intelligence

Citizen Intelligence Agency was first published in 2008 as an open-source initiative focused on political transparency and democratic accountability.

The original ambition was to apply software engineering and data analysis to political information:

- 🔍 Collect public political information.
- 🗃️ Structure fragmented information into usable datasets.
- 🏛️ Make politicians and political institutions easier to examine.
- 📊 Enable systematic analysis of political behaviour.
- 🌍 Make the software and its methodology open to inspection.

CIA was conceived as more than a political news website. It was intended to provide an analytical foundation for examining political activity and institutional accountability.

### 🎯 Foundational principles

| **Principle**              | **Purpose**                                           |
| -------------------------- | ----------------------------------------------------- |
| 🔓 Open source             | Enable independent inspection and reuse               |
| 🌍 Transparency            | Make public information accessible                    |
| 📊 Structured intelligence | Transform fragmented data into analytical information |
| ⚖️ Accountability          | Support scrutiny of political activity                |
| 🛠️ Engineering quality    | Make implementation and quality observable            |

## ☕ 3. 2011: ThinWire, Maven, and XRadar

One of the most valuable surviving historical resources is the Maven-generated legacy documentation site published on **23 January 2011**.

It documents release snapshot `1.0-demo-5-SNAPSHOT`.

**Important historical distinction:** 2011 is the date of this surviving engineering archive, not the beginning of Citizen Intelligence Agency. The project was first published in 2008.

### 🖥️ ThinWire: Java-based rich web interfaces

The original CIA implementation used **ThinWire**, which enabled rich web user interfaces to be developed using Java code.

This is an important part of the project's technical history. The original ThinWire implementation should not be confused with the Vaadin-based interface used in later architecture generations.

### 📚 Maven-generated engineering documentation

The 2011 archive exposes a substantial collection of generated technical documentation:

| **Engineering resource**     | **Purpose**                                         |
| ---------------------------- | --------------------------------------------------- |
| 📖 Javadocs                  | Generated Java API documentation                    |
| 🏗️ UML diagrams             | Software structure and architecture                 |
| 🌱 Spring bean graphs        | Dependency and application configuration visibility |
| 🔗 Dependency analysis       | Component relationships and dependencies            |
| 🧪 Test reports              | Automated test results                              |
| 🔍 Source cross-references   | Navigable source code documentation                 |
| 📊 XRadar reports            | Software quality and structural analysis            |
| 🛠️ FishEye                  | Source control and development visibility           |
| 📦 JBoss Tattletale          | Java dependency and archive analysis                |
| 👥 Contributor documentation | Development and collaboration guidance              |

### 📊 XRadar: Early software quality transparency

XRadar was part of the Maven-generated reporting infrastructure.

It provided a structured way to inspect software quality and architectural characteristics through generated reports.

This demonstrates an engineering philosophy that continued to influence the project:

**Software quality should be observable, documented, and open to scrutiny.**

Historical resources:

- 📊 [XRadar quality reports](https://cia.sourceforge.io/legacy/xradar/index.html)

These are historical resources, not representations of the current software architecture.

## 🏗️ 4. Evolution into a Political Intelligence Platform

Over time, CIA developed into a more comprehensive platform for collecting, structuring, and analysing Swedish parliamentary information.

The platform combined public political data with structured persistence, analytical views, and configurable indicators.

### ⚙️ Architecture evolution

The original ThinWire implementation belongs to the early development period. Later architecture generations adopted a Java enterprise stack.

Documented technologies in later project architecture include:

| **Technology**      | **Role**                                  |
| ------------------- | ----------------------------------------- |
| ☕ Java              | Application development and runtime       |
| 🌱 Spring Framework | Application framework                     |
| 🗄️ Hibernate / JPA | Persistence and object-relational mapping |
| 🐘 PostgreSQL       | Relational data storage                   |
| 🖥️ Vaadin          | Web user interface                        |
| 📦 Maven            | Build and dependency management           |

The later documented architecture includes a Java 21 source baseline, Java 27 runtime documentation, and PostgreSQL 18. These describe later project material, not the 2011 implementation.

### 🔍 Political intelligence capabilities

The platform's analytical foundation includes:

- 👤 Politician profiles and career trajectories.
- 🗳️ Parliamentary voting records.
- 🏛️ Political parties and committee information.
- 📜 Government and parliamentary documents.
- 🔗 Relationships between political actors and institutions.
- 📊 Historical trends and comparisons.
- ⚠️ Configurable analytical rules and risk indicators.

The objective is to make large volumes of public political information accessible for systematic and reproducible analysis.

### ⚖️ Interpreting analytical indicators

Risk indicators are analytical signals, not proof of misconduct.

They can help identify patterns that deserve further investigation, but findings must be evaluated in context and against the underlying public evidence.

This distinction is fundamental to responsible political intelligence.

## 🤖 6. AI-Powered Democratic Intelligence

The later evolution of the CIA ecosystem extended beyond a single application.

AI-enabled workflows and specialised civic technology projects made it possible to transform structured political information into more accessible analysis and reporting.

### 🏛️ Riksdagsmonitor

🔗 [Riksdagsmonitor](https://riksdagsmonitor.com/)\
🔗 [GitHub repository](https://github.com/Hack23/riksdagsmonitor)

Riksdagsmonitor extends the political intelligence foundation with AI-assisted analysis of the Swedish Parliament.

Published capabilities include:

- 🤖 Agentic workflows for recurring political analysis.
- 🧠 Specialised AI skills and analytical tasks.
- 🌍 Multilingual reporting across 14 languages.
- 🗳️ Analysis of parliamentary decisions and voting behaviour.
- 📊 Risk indicators and visualisations.
- 📰 Automated generation of political intelligence reports.

The project combines structured information from CIA with AI-assisted analysis to make parliamentary activity easier to understand.

### 🇪🇺 EU Parliament Monitor

🔗 [EU Parliament Monitor](https://euparliamentmonitor.com/)\
🔗 [GitHub repository](https://github.com/Hack23/euparliamentmonitor)

EU Parliament Monitor applies a similar approach to European parliamentary institutions.

Its purpose is to make public European Parliament information more accessible through structured data, AI-assisted analysis, and multilingual reporting.

### 🔌 European Parliament MCP Server

🔗 [European Parliament MCP Server](https://github.com/Hack23/European-Parliament-MCP-Server)

The Model Context Protocol (MCP) integration provides an interface through which compatible AI assistants and clients can access parliamentary information and tools.

This represents an architectural shift: political intelligence is no longer limited to a dedicated web interface. Structured public information can also be accessed through AI-compatible tools and workflows.

## 📦 9. Project Preservation and Archival Status

In November 2026, the public Hack23 repositories were archived.

This represents a change in operational status. Archival status means the repositories preserve their source code, documentation, and engineering history; it does not imply active maintenance or a commitment to future updates.

The public material remains available as a historical and technical resource for developers, researchers, and anyone interested in civic technology.

### 📚 What remains available

- 🔓 Public source code and repository history.
- 📖 Architecture and engineering documentation.
- 📊 Historical Maven and XRadar reports.
- 🛡️ Security and governance documentation.
- 🏛️ Political intelligence data models and analytical approaches.
- 🤖 AI-assisted civic technology implementations.

The project's history demonstrates the value of long-term open-source work:

1. A project started in 2008 can accumulate a substantial historical data foundation.
2. Engineering decisions can remain inspectable years later.
3. Quality reporting can evolve into modern software assurance.
4. Structured public information can support new analytical applications.
5. Open-source foundations can enable experimentation with emerging technologies such as agentic AI and MCP.

## 💡 10. Eighteen Years of One Underlying Idea

From the original ThinWire-based Java application to AI-assisted political intelligence, the technologies have changed dramatically.

The underlying ambition has not.

Citizen Intelligence Agency began with the belief that public political information should be easier to explore, analyse, and scrutinise.

The 2011 XRadar archive shows that engineering transparency was already part of the project's development culture. Later architecture, automated security assurance, public ISMS documentation, and AI-powered civic technology extended that philosophy into new areas.

The most important lesson is not about a particular framework, programming language, or AI model.

It is about the relationship between transparency and trust.

> **Transparency is not a feature you add at the end. It is an architectural decision.**

— James Pether Sörling
